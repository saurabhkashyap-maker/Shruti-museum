OUR MUSEUM — romantic website

HOW TO OPEN
1. Extract the ZIP file.
2. Open index.html in Chrome, Safari, or another modern browser.
3. Tap “Enter our world”.
4. Tap “Add our photos” and select up to 3 photos from you and your girlfriend.
5. Tap “Music: off” to start the gentle built-in ambient melody. Browsers require a tap before sound can play.

FEATURES
- Dark romantic landing page (no QR-scanning intro)
- Gallery room with framed photos and subtle pointer movement
- Tap frames to view memories larger
- Add up to 3 photos and edit captions
- Gentle synthesized ambient music; no external music file required
- Responsive design for phones and computers

NOTES
- Google Fonts may need internet access; fallback serif/sans-serif fonts are included.
- Uploaded photos are displayed in the current browser session; this starter version does not upload them to a server or save them permanently.
- The gallery is a lightweight CSS 3D-inspired experience rather than a full 3D game engine.
